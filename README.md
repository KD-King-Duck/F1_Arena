# F1 Arena
1. Copie le dossier dans `C:\xampp\htdocs\F1_Arena`, démarre Apache + MySQL.
2. Dans phpMyAdmin, importe `F1_BDD.sql` (crée la base `f1_arena`).
3. Ouvre http://localhost/F1_Arena/index.html
Identifiants MySQL : `config.php` (par défaut root, sans mot de passe).
Ordre conseillé : écuries → pilotes → calendrier → résultats.
